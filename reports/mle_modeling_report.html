Data contract

  • Numeric (nulls OK): age, daily_screen_time_hours, social_media_hours, gaming_hours, work_study_hours, sleep_hours, notifications_per_day, app_opens_per_day, weekend_screen_time.
  • Categorical (nulls OK): gender {Male, Female, Other}, stress_level {Low, Medium, High}, academic_work_impact {Yes, No}.
  • Split: StratifiedKFold on the label, shuffle, seed from YAML (42), default 5 folds. Diagnostics rename to *_diag* and are not competition scores.
  • Leakage: never use id as a feature; TE must be fold-safe (and is a proven GBM dead-end); do not concat the original ~7,500-row source (different component dependence).
  • Train/serve: one transform, s6e8.features.transform. Audit CLI: python scripts/audit_data.py.

How to run

Local / CI smoke (no competition score)

python3 -m compileall -q -x '(\.venv|venv)' .
python3 scripts/train.py --help
python3 scripts/validate_configs.py
python3 -m pytest -q

Train (needs data/raw or a Kernel mount)

python3 scripts/train.py --config configs/lgbm_nocat.yaml
python3 scripts/train.py --config configs/lgbm_nocat_seedbag.yaml
python3 scripts/train.py --config configs/catboost_nocat.yaml
python3 scripts/train.py --config configs/histgb_nocat_moreiter.yaml --max-train-rows 80000 --n-splits 3

Post-hoc (needs oof/<parent>/)

python3 scripts/blend_oof.py --experiments lgbm_nocat_seedbag catboost_nocat --method grid --name blend_seedbag_catboost --write-experiment-record
python3 scripts/stack_oof.py --experiments lgbm_nocat histgb_nocat --name stack_logistic_lgbm_histgb --write-experiment-record
python3 scripts/calibrate_oof.py --experiment lgbm_nocat --method isotonic
python3 scripts/promote.py --candidate lgbm_nocat_seedbag --baseline lgbm_nocat
python3 scripts/audit_data.py --config configs/baseline.yaml
python3 scripts/error_analysis.py --experiment lgbm_nocat

Kaggle Kernel

GitHub Actions workflow Kaggle Train packages the repo and pushes kaggle/runner.py, which calls the same scripts/train.py --config …. Set accelerator in the workflow input to override YAML. Leave submit_to_kaggle false unless you intend a leaderboard row; the message must include the experiment name. Full 5-fold LightGBM is often 30–180 minutes on CPU. Do not run that 5-fold on GitHub Actions runners or this cloud VM.

Remaining risks and exhaustion claim

Local/config-driven modeling surfaces are exhausted: every high-value family has a trainer and a unique config (or a documented skip), and arithmetic / encoding / ExtraTrees / linear-stack / LightGBM-extra_trees / CatBoost-cats paths were falsified on real 80k×3 data using the same protocol as the existing ranking log.

  • Hard-band (80k sample: 12,219 rows, AUC 0.637; full-data ~93k / 0.641) remains the error mass. Residual column AUC max 0.516. Seed bagging is the ensemble step that error analysis asked for.
  • Missing flags (+0.000144) do not clear fold std. Interactions hurt (−0.00135). LightGBM extra_trees hurt (−0.015). Do not 5-fold them.
  • sklearn ExtraTrees is weaker than LGBM and receives blend weight 0. CatBoost matches LGBM on 80k and is the better blend partner than HistGB on this protocol.
  • LGBM is already well calibrated (ECE 0.0042). Platt made ECE worse. Skip calibration for ranking.
  • Do not mix original 7,500 rows into train. Do not GPU-force baseline LightGBM.

There is no further high-value local modeling path left unimplemented. Remaining work is Kernel compute: full 5-fold lgbm_nocat_seedbag (80k +0.00172, ranking-only) and optional catboost_nocat + grid blend. Until those metrics.json files exist from a non-diagnostic run, the production-equivalent submissions remain lgbm_nocat / blend_nocat.
